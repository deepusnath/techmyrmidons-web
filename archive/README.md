# Archive: the original Techmyrmidons (2018-2021)

The first Techmyrmidons curated per-domain, per-year tool lists, experts to follow, and best blogs across 12 domains, entirely by hand, from 2018 to 2021. This folder preserves that work exactly as it was: it is the historical record of how the landscape looked before the AI era, and of the contributors who built it.

The living successor is the [radar system](../radars/README.md).
